# 萌宠防线 / Pet Pals Defense

蜡笔风宠物塔防。打开下面的网址就能玩，不用下载。进度会自动保存在你自己的浏览器里，下次用同一台设备、同一个浏览器打开，进度还在。

A crayon-style pet tower defense game. Open the link to play — no download needed. Progress is saved automatically in your browser, so it will still be there the next time you open this same site on the same device and browser.

**Play / 开始玩：** https://carden1218-create.github.io/pet-pals-defense/

第一次打开会先让你选「中文」或「English」。开局送你一只宠物，在无尽模式里打史莱姆、捡蛋、孵化、培养和进化。

The first time you open the game, pick **中文** or **English**. You start with one pet, then fight slimes in Endless mode, collect eggs, hatch, train, and evolve.
